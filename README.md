# Hospital Emergency Room (ER) Analytics Dashboard

## 🏥 Project Overview
This project focuses on analyzing Hospital Emergency Room  operational data to gain insights into patient flow, treatment efficiency, and overall healthcare delivery. I have processed raw healthcare data and transformed it into an interactive Excel dashboard to help hospital administrators make data-driven decisions.

![Hospital Emergency Room Dashboard](Hospital%20Dashboard.png)

## 🛠️ Tech Stack & Tools
- **Microsoft Excel:** Data Cleaning, Pivot Tables, and Dashboard Design.
- **Power Query:** Data Transformation and Normalization.
- **Data Visualization:** Custom Charts, Slicers, Sparklines, and Conditional Formatting.

## 📊 Key Insights & Metrics
- **Patient Volume:** Analyzed data for **479 patients** to understand peak hours and load.
- **Wait Time Analysis:** Monitored an average wait time of **34.90 minutes**, using sparklines to identify trends and bottlenecks.
- **Patient Satisfaction:** Tracked a satisfaction score of **5.30/10**, highlighting areas for service improvement.
- **Demographics:** Visualized patient distribution across age groups (0-79) and gender (51% Male, 49% Female).
- **Department Performance:** Identified **General Practice** as the highest-volume department, followed by Cardiology and Physiotherapy.
- **Operational Efficiency:** Observed that **43%** of patients are treated on time, while **57%** experience delays.

## 🚀 Interactive Features
- **Time-Based Slicers:** Filter data by Year (2023, 2024) and specific Months to track seasonal trends.
- **Departmental Breakdown:** Dynamic bar charts to compare patient load across different medical departments.
- **Admission Status:** Visual representation of Admitted vs. Non-Admitted patients.
